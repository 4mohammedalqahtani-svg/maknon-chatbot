# المساعد الذكي لجمعية مكنون لتحفيظ القرآن الكريم

شات بوت عربي بالكامل يجيب على أسئلة الزوار والموظفين اعتمادًا على مستندات الجمعية
الموجودة في مجلد Google Drive، ويُستضاف مجانًا على Netlify.

👉 **للتنصيب خطوة بخطوة اقرأ [SETUP_AR.md](./SETUP_AR.md)** — دليل عربي كامل للمبتدئين.

👉 **لربط المساعد بالواتساب اقرأ [WHATSAPP_SETUP_AR.md](./WHATSAPP_SETUP_AR.md)** — نفس المعرفة والضوابط على رقم واتساب.

## المعمارية

1. **قراءة الدرايف:** `lib/drive-sync.mjs` يقرأ مجلد الدرايف عبر Drive API (بمفتاح API بسيط،
   بلا OAuth ولا Service Account)، ويستخرج النص من كل الملفات. يحدث هذا في مكانين:
   - **كل ليلة بدون نشر:** `refresh-schedule` يطلق `refresh-knowledge` الذي يحفظ المعرفة في
     Netlify Blobs، فيستخدمها الشات فورًا. لا يستهلك رصيد النشر (النشر = 15 رصيدًا من 300 شهريًا).
   - **عند كل نشر:** `scripts/sync-drive.mjs` يبني `knowledge-data.mjs` كنسخة احتياطية.
   الشات يستخدم الأحدث من النسختين.
2. **اختيار الوضع تلقائيًا:**
   - المحتوى ≤ 60,000 توكن → **وضع النص الكامل**: كل النصوص داخل تعليمات النظام الثابتة،
     فيستفيد تلقائيًا من التخزين المؤقت للمدخلات لدى OpenAI (خصم 90%).
   - أكبر من ذلك → **وضع embeddings**: تقطيع + `text-embedding-3-small`،
     وبحث بالتشابه داخل الملف نفسه بدون قاعدة بيانات خارجية.
3. **وقت الطلب:** `netlify/functions/chat.mjs` يتحقق من الأصل والمعدّل والطول،
   ثم يبثّ إجابة OpenAI سطرًا سطرًا بصيغة NDJSON.

## الأوامر

```bash
npm install
```

```bash
npm run sync
```

```bash
netlify dev
```

| الأمر | الوظيفة |
|---|---|
| `npm install` | تثبيت المكتبات |
| `npm run sync` | قراءة الدرايف وبناء ملف المعرفة (يطبع تقريرًا) |
| `npm run build` | نفس `sync` — يشغّله Netlify تلقائيًا عند كل نشر |
| `netlify dev` | تشغيل الموقع والوظيفة محليًا على `localhost:8888` |

## الحماية

- المفاتيح في متغيرات البيئة فقط، ولا تصل إلى المتصفح.
- رفض الطلبات القادمة من خارج نطاق الموقع (فحص `Origin`).
- حد لطول السؤال وحد لطول الإجابة.
- تحديد معدّل لكل زائر: في الدقيقة وفي اليوم.
- تعليمات النظام مقاومة لمحاولات تغيير الدور (prompt injection).
- منع تأليف الآيات والأحاديث والفتاوى منعًا باتًا.
